04 / Workflow Proctor CLI

The 30-second
developer workflow

Three commands to capture, verify, and gate agent execution locally.

# 1. Run the agent under Proctor
$ npx --yes @genramzi/proctor run -- claude
# 2. Verify the evidence
$ npx --yes @genramzi/proctor verify
# 3. Gate the pull request
$ npx --yes @genramzi/proctor gate
Seamless wrapping
The wrapped agent’s output streams to the terminal without interruption.
Portable artifacts
A complete evidence receipt is written to .proctor/<run-id>.receipt.json.
Shift-left review
Failed claims or high-signal green-wash findings become visible before merge.
Flexible inputs
Use --claims-file when the agent’s final report is separate from the transcript.
