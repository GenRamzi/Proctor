08 / CI Integration GitHub Action

From local run to pull-request gate

permissions:
  contents: read
  pull-requests: write

- name: Verify the Work Receipt
  uses: GenRamzi/Proctor@main
  with:
    receipt: .proctor/latest.receipt.json
    strict: "false"
    comment: "true"
1. Locates the receipt
Finds the configured path or the newest timestamped receipt in .proctor/.
2. Runs gate & generates badge
Executes the policy gate and creates an SVG Integrity badge.
3. Uploads evidence bundle
Attaches the receipt and badge as a workflow artifact.
Pull Request Integration
The Action can comment directly on pull requests. If comment permissions are restricted (e.g., on fork PRs), it gracefully falls back to the artifact upload without hiding the underlying gate exit code.
