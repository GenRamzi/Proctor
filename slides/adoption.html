06 / Adoption Low-friction path

Adopt Proctor without changing your agent

1. Start with one command
Wrap your existing workflow seamlessly: proctor run -- <agent-command>
2. Add privacy controls
Use .proctorignore to exclude .env*, secrets, keys, and generated artifacts from snapshots.
3. Use flexible inputs
Pass --claims-file for structured agent handoff reports when claims aren't in the transcript.
4. Strict-mode progression
Begin with advisory verify. Move to gate --strict after reviewing initial findings.
Development extensibility
Extend safely with deterministic parsers, rules, fixtures, and tests. Distributed as @genramzi/proctor@0.1.0 (Requires Node.js 20+).
