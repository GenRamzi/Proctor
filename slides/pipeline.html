03 / Architecture Data flow & Privacy

One local-first pipeline,
four useful outputs

01
Run
Execute the agent through a PTY wrapper and snapshot the workspace before and after.
02
Analyze
Parse supported test output and apply deterministic green-wash rules to the ledger.
03
Receipt
Store evidence, claims, findings, integrity score, and hash-chain metadata in JSON.
04
Decide
Use verify, gate, inspect, or badge for the next workflow step.
Local-first privacy model
Source code and transcripts are not sent to a hosted model by default. Proctor relies on deterministic, local execution evidence.
