07 / Detectors Green-wash taxonomy

Green-wash detectors create a shared vocabulary

GW-001
SCOPE-NARROWED
Full-suite claim + captured filter
GW-003
TEST-DELETED
Before/after file hashes
GW-004
ASSERT-WEAKENED
Test diff or changed test content
GW-007
STUB-RETURN
Implementation diff + constant return
GW-012
HOOK-BYPASSED
Git operation or transcript
GW-014
NEVER-RAN
Claim without executed verification
Conservative Evidence Policy
v0.1 ships deterministic implementations for GW-001 through GW-008, GW-012, and GW-014. Every finding must cite evidence; missing evidence is not an accusation.
