02 / Solution Evidence Model

Proctor turns agent claims into reviewable evidence

1. Wrap any CLI agent
Works with Claude, Codex, Aider, or any custom script.
2. Capture deterministic ledger
Records command, transcript, file mutations, tests, and Git signals.
3. Emit portable Work Receipt
Produces a single JSON artifact for local review and CI gating.
Claim Adjudication Verdicts
PROVEN
Ledger contains direct supporting evidence.
CONTRADICTED
Captured evidence conflicts with the claim.
UNPROVEN
Plausible, but ledger lacks sufficient evidence.
UNVERIFIABLE
Qualitative or outside execution evidence scope.
