What developers get after the run

Gate decision
A CI-safe exit code for merge policy enforcement.
Review report
Detailed claims, verdicts, findings, and integrity deductions.
Evidence bundle
JSON receipt, report, and integrity.svg artifact.
Pull-request context
Optional summary comment with the captured result.
Score Interpretation
The score summarizes claim/evidence integrity. It is not a correctness, code-quality, or coverage score.
