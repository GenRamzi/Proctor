03 / ConfigurationYAML Workflow

A ready-to-copy workflow

name: Proctor Integrity Gate
on: pull_request
permissions: { contents: read }
jobs:
  proctor-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npx --yes @genramzi/proctor run --claims-file ./agent-report.md -- your-agent-command
      - uses: GenRamzi/Proctor@main
        with: { receipt: .proctor/latest.receipt.json }
Drop this into .github/workflows/proctor-gate.yml
A complete, secure setup for auditing agent execution in CI.
