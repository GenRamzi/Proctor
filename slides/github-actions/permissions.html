04 / Security Permissions

Permissions are a security decision

permissions:
  contents: read
  pull-requests: write
contents: read
Allows checkout and read-only repository access.
pull-requests: write
Allows Proctor to post a summary comment.
Least privilege
Use the minimum permissions required. Remove pull-requests: write if PR comments are not needed.
Fork PR caution
Treat fork pull requests as untrusted execution contexts. Repository security restrictions may prevent write access.
Secret handling
Never expose signing keys, npm publish tokens, or cloud credentials to the agent process.
A missing comment permission should not erase the gate result.
Keep the artifact upload and gate exit code as the source of truth.
