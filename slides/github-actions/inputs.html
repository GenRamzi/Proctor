06 / Configuration Action Inputs

Tune the gate with three Action inputs

receipt
Default: newest receipt
Selects the specific Work Receipt to inspect.
strict
Default: "false"
Makes UNPROVEN claims fail the gate when set to true.
comment
Default: "true"
Posts a pull-request summary when permissions allow.
Automatic Artifacts
The Action automatically generates an SVG Integrity badge and uploads the receipt/report bundle as a workflow artifact.
Resilient execution
A missing comment permission should not erase the gate result or artifact.
