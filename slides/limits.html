10 / Limitations & Roadmap Future Direction

Evidence first, automation second

Anti-goals & Limitations
  • Not a correctness oracle, code reviewer, telemetry platform, or model judge.
  • The current release does not fully observe every child process or provide native adapters for every agent.
  • The score summarizes claim/evidence integrity, not code quality or test coverage.
Roadmap
  • Language packs and richer AST evidence.
  • Native agent adapters for tighter integration.
  • Sigstore integration for verifiable receipts.
  • Homebrew distribution for easier installation.
  • proctor watch daemon to interrupt runs on high-confidence findings.
The core philosophy
Proctor relies on deterministic, local execution evidence. Every finding must cite evidence, and Proctor remains silent when evidence is absent.
